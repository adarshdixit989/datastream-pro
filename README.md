# DataStream Pro — Enterprise Real-Time Analytics Platform

Production-style real-time analytics platform built with Django, Apache Kafka, Redis, PostgreSQL, Scikit-learn, Docker and AWS-ready deployment components.

## Features
- Kafka event streaming and ingestion
- Redis real-time counters
- PostgreSQL persistence
- ML anomaly detection with Isolation Forest
- Rolling forecasting
- React + TypeScript analytics dashboard
- Docker Compose local stack
- GitHub Actions CI/CD
- AWS deployment blueprint
- Load-test/benchmark tooling
